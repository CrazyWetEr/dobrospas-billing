# dobrospas-billing

Анализ биллинга и построение зон покрытия (PWA, GitHub Pages). **v8.0**

## Что нового в v8.0
- Исправлено: выбор вышки/сектора/зоны в списках теперь подгружает поля (раньше «Сохранить» перезаписывало данные чужими значениями)
- Исправлено: экспорт JSON и бэкап (циклическая структура), кнопка «Импорт JSON», восстановление бэкапа с проверкой данных и азимутами
- Исправлено: зависание при ширине сектора 0, дублирование ID вышек, XSS в названиях, невалидный GPX (xmlns, экранирование)
- Исправлено: вид и слой карты запоминаются, лимит узлов сетки, ошибки сохранения видны, геолокация с ошибками
- Новое: пересечение отмеченных секторов (turf.js), площадь/периметр полигона, отмена последней вершины (Ctrl+Z), импорт вышек из CSV, экспорт KML, поиск по координатам (DD / DMS), откат последних состояний, офлайн-кэш тайлов области, уведомление об обновлении

## CSV вышек
Колонки: `lat, lng, azimuth` (обязательные), `name, cellid, operator, width, radius` (необязательные). Разделитель `;`, `,` или Tab. Строки с одинаковыми координатами и CellID объединяются в одну вышку с несколькими секторами.
